# PPG • Internship Protocol Management

PPG is a Laravel-based web application created to manage internship protocol workflows, academic documents, and administrative validation processes for ISCAP/PPG.

The application supports students through document selection, dynamic form completion, protocol generation, download in PDF or DOCX format, and upload of a final signed document. Administrators can manage courses, templates, users, validations, presidential email approvals, and reporting.

## Main capabilities

- Student registration, authentication, and email verification
- Course-based document selection and dynamic field entry
- Automatic PDF/DOCX generation for protocol documents
- Upload of signed final protocol files
- Administrative management of document templates and validation workflows
- Report generation, export, and audit logs

## Technologies used

- PHP 8.2+
- Laravel 12
- Blade templates
- MySQL / MariaDB or SQLite
- PHPMailer, Dompdf, PhpWord, PhpSpreadsheet
- Tailwind/static CSS for the interface

## Purpose

This system is intended to centralize internship protocol submission and approval, simplify academic administrative work, and preserve document history and validation tracking.
